# GAINT Interns Hub V8.1 — Complete Flow

## Individual student

Register → verify contact → log in → select FastTrack/45 Days/Semester → select
technology → select project and track → see price and certification rule →
accept policy → pay once → read Student Guide → download starter → install the
included GAINT extension once → open project in VS Code → implement the current
real-project milestone and checkpoint → submit current task → required files +
local checks + visible/hidden Judge0 cases decide pass/fail → pass unlocks next
task; fail permits correction/retry → all tasks pass → final whole-project
source and build checks → clean runnable local ZIP → certificate and evaluation
report enabled.

Individual students have no attendance and no College Coordinator. If they do
not pass, payment is not refunded as a certificate promise: it paid for project
access and evaluation attempts. They can retry through their access and grace
period (FastTrack 7, 45 Days 15, Semester 30 extra days).

## College student

Admin creates college Coordinator and MOU → selects validity, active status,
1–500 limit and allowed projects → system creates student credentials → student
logs in and changes temporary password → seat activates under valid MOU →
student selects program, technology, allowed project and track → no payment →
read Student Guide → download starter → work/submit sequentially from local VS
Code → task checks control unlocks → all tasks pass → certificate, report and
clean runnable ZIP → student presents/runs the project locally at college.

College attendance is enabled. The Coordinator sees only students from that
college. An expired/inactive MOU blocks new seats and new project access; Admin
must update it.

For a college team project only, Admin can assign one approved project to
separate Frontend and Backend students. Each receives track-specific required
folders and tasks. Coordinator monitors both streams. After every member passes
their own final validation, GAINT detects source conflicts and creates one
combined runnable team ZIP. Individual internships remain one-person projects.

## Task lifecycle

Locked → current task opens → student updates required real project files →
student completes checkpoint → extension sends a limited snapshot of required
text-source files (never secrets, dependencies or local DB) → backend verifies
hashes, syntax, required paths, starter changes and placeholders → extension runs
configured local build/tests → checkpoint goes to Judge0 → all checks pass =
PASSED → next task opens. Any missing project evidence, failed local command,
compile error, wrong output or hidden edge case keeps the task open.

During the current task, the GAINT Learning Assistant can explain the milestone,
give a limited hint and help diagnose setup, VS Code, local-test or Judge0
errors. It cannot provide the complete answer, view hidden tests, pass a task,
unlock a task or issue a certificate.

Only the current question is returned. Future questions and hidden tests remain
on the backend.

## Completion

Final task PASSED → extension reruns all required project checks → backend
validates the final source snapshot → backend issues certificate → evaluation
report enabled → extension excludes checkpoints, GAINT metadata, secrets,
caches and dependencies → extension writes a clean completed ZIP beside the project →
student uses its setup/start documentation and included local SQLite database
for local college presentation.

## Admin

Log in → create Mentor analytics accounts → create Coordinators/MOUs → set
student limits, dates, status and project access → download generated student
credentials → upload/scan complete predefined source ZIPs or generate projects →
set technology, program, fee and tracks → publish → monitor all students,
payments, task progress, certificates, reports and audit history.

## College Coordinator

Log in with Admin-provided credentials → see compact MOU status and seat counts
→ monitor only assigned-college students → monitor attendance, selected project,
task progress and Judge0 state → update authorised attendance → download college
progress CSV. No individual students, payments, MOU editing, task passing,
unlocking or certificate issuing.

## Mentor

Log in with company credentials → see aggregate number of colleges, active
MOUs, college/individual students, chosen technology stacks, program periods,
started projects, in-progress projects and completions. No student-level review,
feedback, viva, pass, unlock or certificate action.
